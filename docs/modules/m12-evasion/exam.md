# Контрольная M12 — обход защиты

> Время: 🟢 60 мин · 🟡 4 ч · 🔴 8 ч. Сдаётся в `labs/m12-evasion/exam/`.

## 🟢 Задача 1. Карта защиты (60 мин)

**Дано:** `WIN01` с Defender.

**Задание:**
1. Соберите baseline: версия, real-time, ASR, AppLocker/WDAC.
2. Определите, какие слои активны.
3. Нарисуйте путь payload и отметьте точки детекта.
4. Предложите по одному тесту на каждый слой.

**Сдать:** `baseline.md`, `map.md`.

**Критерии:** baseline (30), карта (40), тесты (30).

---

## 🟡 Задача 2. Лоадер и LOLBin (4 ч)

**Дано:** `WIN01`, `LNX01`.

**Задание:**
1. Соберите минимальный лоадер (C) и запустите.
2. Доставьте файл через `certutil`.
3. Выполните HTA/скрипт через `mshta`.
4. Для каждого шага соберите 4688/Sysmon.
5. Сравните: что заблокировано, что нет.
6. Предложите 2 правила детекта.

**Сдать:** `loader/` — `code/`, `steps.md`, `events.md`, `rules.md`.

**Критерии:** лоадер (25), LOLBin (25), телеметрия (25), правила (25).

---

## 🔴 Задача 3. Контролируемый тест (8 ч)

**Дано:** `WIN01` + Defender, опционально EDR trial.

**Задание:**
1. Сформулируйте 3 гипотезы (например: «in-memory не детектится», «LOLBin не детектится», «ASR блокирует LSASS dump»).
2. Проведите по одному эксперименту на гипотезу.
3. Соберите prevention/detection/visibility.
4. Постройте матрицу и график «время до детекта».
5. Опишите, какие слои дали детект.
6. Дайте рекомендации: 3 детекта + 3 hardening-меры.
7. Оформите как короткий research-note (2–3 страницы).

**Сдать:** `research/` — `hypotheses.md`, `results.md`, `matrix.md`, `recommendations.md`, `note.md`.

**Критерии:** гипотезы (15), эксперименты (25), данные (20), выводы (20), рекомендации (20).
