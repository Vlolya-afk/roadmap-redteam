# Контрольная M19 — mobile

> Время: 🟢 90 мин · 🟡 4 ч · 🔴 8 ч. Сдаётся в `labs/m19-mobile/exam/`.

## 🟢 Задача 1. Реверс APK (90 мин)

**Дано:** учебное APK (DIVA/InsecureBankv2/AndroGoat).

**Задание:**
1. Декомпилируйте `apktool` и `jadx`.
2. Разберите Manifest: exported, permissions, backup.
3. Найдите 3 строки/секрета.
4. Проверьте хранилище через `adb`.
5. Опишите 3 риска.

**Сдать:** `apk/` — `manifest.md`, `secrets.md`, `storage.md`, `risks.md`.

**Критерии:** декомпиляция (25), manifest (25), секреты (25), риски (25).

---

## 🟡 Задача 2. Динамика и pinning (4 ч)

**Дано:** APK с pinning, эмулятор, Frida, прокси.

**Задание:**
1. Подключите Frida.
2. Перехватите метод логина.
3. Обойдите pinning.
4. Перехватите трафик в прокси.
5. Найдите 2 API-риска.
6. Опишите детект и фикс.

**Сдать:** `dynamic/` — `hooks/`, `traffic/`, `findings.md`, `fix.md`.

**Критерии:** Frida (25), pinning (25), трафик (20), находки (15), фикс (15).

---

## 🔴 Задача 3. Полный отчёт MASTG (8 ч)

**Дано:** приложение (Android + iOS, если доступно).

**Задание:**
1. Составьте план по MASVS.
2. Проведите статику и динамику.
3. Найдите 8+ находок.
4. Для каждой — доказательство и фикс.
5. Оцените риск и приоритет.
6. Оформите отчёт по MASTG.
7. Дайте executive summary.

**Сдать:** `report/` — `plan.md`, `findings.md`, `evidence/`, `exec.md`, `report.md`.

**Критерии:** план (15), находки (30), доказательства (20), приоритизация (20), отчёт (15).
