# M19 — Mobile и реверс

> **Этап 3 · 3 занятия · ~16 часов · артефакты в `labs/m19-mobile/`**

## Зачем этот модуль

Мобильные приложения — это API-клиенты с локальным хранилищем, сертификатами и своим кодом. Ошибки здесь дают доступ к данным и бэкенду, а навык реверса переносится на любые бинарники.

## Чему научитесь

- Разбирать APK: структура, smali, dex, ресурсы.
- Работать с `adb`, эмулятором и Frida.
- Обходить certificate pinning и root detection.
- Проводить мобильный пентест по MASTG.
- Кратко оценивать iOS.
