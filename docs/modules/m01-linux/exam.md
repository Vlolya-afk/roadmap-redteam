# Контрольная M01 — Linux

> Время: 🟢 60 мин · 🟡 2–3 ч · 🔴 4–6 ч. Сдаётся в `labs/m01-linux/exam/`.

## 🟢 Задача 1. Права и пользователи (60 мин)

**Дано:** чистый Arch, пользователи `alice`, `bob`, `carol`.

**Задание:**
1. Создайте группу `finance` и каталог `/srv/finance`, куда могут писать только члены группы, а читать — никто посторонний. Новые файлы должны наследовать группу `finance`.
2. Дайте `bob` read-only доступ к конкретному файлу через ACL, не добавляя его в группу.
3. Найдите все SUID-файлы и объясните, какие два самых опасных и почему.
4. Покажите `sudo -l` для `alice` с правом только на `systemctl status`, без shell.

**Сдать:** `perms.md` с командами, `ls -l`, `getfacl`, `sudo -l`, объяснением.

**Критерии:** SGID и права (30), ACL (20), SUID-анализ (30), sudo (20).

## 🟡 Задача 2. Найти persistence (2–3 ч)

**Дано:** ВМ, в которой оставлены **пять** закладок из урока 1.5 (или аналогичных). Доступ по SSH с вашим ключом.

**Задание:**
1. Найдите все пять, не используя готовые сканеры.
2. Для каждой укажите: механизм, что она даёт атакующему, как её удалить.
3. Составьте таймлайн: когда появились файлы (по `stat`/логам).
4. Напишите `cleanup.sh`, который удаляет все пять идемпотентно.

**Сдать:** `hunt/incident.md`, `hunt/cleanup.sh`, `hunt/evidence/`.

**Критерии:** найдены 5/5 (40), объяснение (25), таймлайн (15), cleanup (20).

## 🔴 Задача 3. Аудит-скрипт уровня portфолио (4–6 ч)

**Дано:** две ВМ — чистая и с закладками.

**Задание:**
1. Напишите `audit.sh` (bash или Python), который собирает:
   - пользователей UID 0 и пустые пароли;
   - SUID/SGID и world-writable файлы вне ожидаемых путей;
   - listening-порты с процессами;
   - cron, systemd-юниты, таймеры с подозрительными путями;
   - `authorized_keys` и ключи без passphrase (если определимо);
   - файлы, изменённые за последние 24 часа.
2. Отчёт — Markdown + JSON, с severity и ссылкой на команду-доказательство.
3. Запустите на чистой и заражённой ВМ, сравните: false positives, пропуски.
4. README: установка, использование, ограничения, тесты.

**Сдать:** `audit/` — `audit.sh`, `README.md`, `clean.md`, `infected.md`, `diff.md`.

**Критерии:** полнота (30), качество отчёта (20), FP/FN-анализ (20), код и тесты (20), README (10).
