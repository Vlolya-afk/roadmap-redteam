# Контрольная M02 — сети

> Время: 🟢 60 мин · 🟡 2–3 ч · 🔴 4–6 ч. Сдаётся в `labs/m02-networking/exam/`.

## 🟢 Задача 1. Подсети и перехват (60 мин)

**Дано:** сеть `10.10.10.0/24`, цель `10.10.10.30`.

**Задание:**
1. Разбейте `/24` на 4 подсети и укажите для каждой network/broadcast/диапазон.
2. Захватите HTTP-трафик с Basic-аутентификацией и декодируйте логин/пароль.
3. Объясните, какие три пакета открывают TCP-сессию и какие флаги в них.
4. Предложите два способа защитить передачу пароля.

**Сдать:** `subnets.md`, `capture.pcap` (не в git, ссылка + SHA256), `creds.txt` (пароль замазан), `answers.md`.

**Критерии:** подсети (30), перехват и декод (30), TCP (20), защита (20).

## 🟡 Задача 2. Диагностика по pcap (2–3 ч)

**Дано:** pcap, в котором пользователь жалуется: «сайт открывается, но большие файлы зависают», а иногда «вообще ничего не грузится».

**Задание:**
1. Найдите в pcap признаки:
   - MTU/fragmentation issue (большие пакеты не проходят);
   - DNS-ответ с неверным адресом или таймаут;
   - ретрансмиссии и дубли ACK.
2. Для каждой проблемы объясните механизм и предложите фикс.
3. Напишите `diagnose.sh`, который по pcap выводит: топ-источников, ретрансмиссии, DNS-ошибки.

**Сдать:** `diagnosis.md`, `diagnose.sh`, `evidence/` (скриншоты Wireshark).

**Критерии:** найдены 3 проблемы (45), объяснение (25), скрипт (20), оформление (10).

## 🔴 Задача 3. Сегментация и разбор атаки (4–6 ч)

**Дано:** хост Arch с двумя интерфейсами, две подсети: `10.10.10.0/24` (цели) и `192.168.56.0/24` (management).

**Задание:**
1. Настройте nftables так, чтобы:
   - management мог ходить в цели только по TCP 22, 80, 443;
   - цели не могли инициировать соединения в management;
   - established/related разрешены;
   - ICMP разрешён только из management.
2. Соберите pcap атаки: ARP spoof (ручной, через `ip neigh`) + HTTP-запрос с Basic auth. Покажите, как перехват выглядит в трафике.
3. Опишите, какие правила/логи поймали бы это, и почему сегментация не спасает от ARP-спуфинга внутри одной подсети.
4. Сдайте `firewall.nft`, `topology.md`, `analysis.md`.

**Критерии:** правила корректны и не ломают established (30), pcap и разбор (25), понимание ограничений (25), документация (20).
