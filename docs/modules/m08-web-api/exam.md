# Контрольная M08 — web/API

> Время: 🟢 90 мин · 🟡 4 ч · 🔴 6–8 ч. Сдаётся в `labs/m08-web-api/exam/`.

## 🟢 Задача 1. DVWA (90 мин)

**Дано:** DVWA security `low`.

**Задание:**
1. SQLi: вытащите логин и хэш администратора.
2. Stored XSS: payload, который срабатывает при повторном открытии.
3. LFI: прочитайте `/etc/passwd` и исходник `index.php` через filter.
4. Upload: загрузите PHP-файл и докажите выполнение.
5. Для каждой — причина и фикс.

**Сдать:** `dvwa/` — payload'ы, вывод, `report.md`.

**Критерии:** 4/4 (60), объяснение (20), фиксы (20).

---

## 🟡 Задача 2. JWT и BOLA (4 ч)

**Дано:** `jwt_app.py`, Juice Shop.

**Задание:**
1. Получите JWT, определите алгоритм и claims.
2. Сломайте секрет и подделайте `role=admin`, докажите доступ.
3. Проверьте `alg:none` и `kid`.
4. В Juice Shop найдите BOLA с двумя пользователями.
5. Опишите, как исправить обе проблемы.

**Сдать:** `auth/` — токены (обрезанные), скрипты, `report.md`.

**Критерии:** JWT (40), BOLA (30), фиксы (20), оформление (10).

---

## 🔴 Задача 3. API-отчёт (6–8 ч)

**Дано:** Juice Shop или crAPI.

**Задание:**
1. Составьте карту API: эндпоинты, методы, авторизация.
2. Найдите минимум 6 проблем разных классов (BOLA, mass assignment, rate limit, GraphQL, auth, injection).
3. Для каждой: PoC, влияние, CVSS, remediation, retest.
4. Проверьте 5 гипотез, которые **не** подтвердились, и объясните почему.
5. Executive summary + technical appendix.

**Сдать:** `api-report/` — `map.md`, `findings/`, `poc/`, `report.md`, `retest.md`.

**Критерии:** карта (15), находки (35), PoC (20), remediation (20), отчёт (10).
