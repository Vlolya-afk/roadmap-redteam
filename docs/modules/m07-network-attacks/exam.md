# Контрольная M07 — сетевые атаки

> Время: 🟢 60 мин · 🟡 3 ч · 🔴 6–8 ч. Сдаётся в `labs/m07-network-attacks/exam/`.

## 🟢 Задача 1. MITM и креды (60 мин)

**Дано:** WS01 (10.10.10.20), LNX01 (10.10.10.30), attacker.

**Задание:**
1. Проведите ARP spoof между WS01 и LNX01.
2. Перехватите HTTP Basic-аутентификацию.
3. Докажите, что связь не прервалась (forwarding).
4. Восстановите ARP и покажите, что MAC вернулся.

**Сдать:** `mitm.md`, pcap (ссылка + SHA256), скрин `arp -a` до/после.

**Критерии:** MITM (35), креды (25), forwarding (20), восстановление (20).

---

## 🟡 Задача 2. Poisoning + relay (3 ч)

**Дано:** WS01, Samba на LNX01, домен.

**Задание:**
1. Соберите NetNTLMv2 через Responder и сломайте его (или докажите стойкость).
2. Проверьте SMB signing на трёх хостах.
3. Проведите relay на Samba с `server signing = no`.
4. Включите обязательную подпись и докажите, что relay перестал работать.
5. Опишите 3 события/лога, которые это фиксируют.

**Сдать:** `relay/` — конфиги, логи, `report.md`.

**Критерии:** hash (25), signing (20), relay (30), проверка фикса (15), детекты (10).

---

## 🔴 Задача 3. Оценка L2 и харденинг (6–8 ч)

**Дано:** лаборатория из 4+ хостов.

**Задание:**
1. Проведите оценку: ARP, LLMNR, DHCP, SMB signing, LDAP signing.
2. Реализуйте rogue DHCP и покажите перехват.
3. Составьте матрицу «атака → контроль → детект → остаточный риск».
4. Внедрите 5 мер (GPO/registry/Samba) и проверьте каждую.
5. Напишите 3 детекта и протестируйте их на повторной атаке.
6. Отчёт 8–12 страниц + executive summary.

**Сдать:** `l2-assessment/` — `matrix.md`, `hardening/`, `detections/`, `report.md`.

**Критерии:** оценка (20), rogue DHCP (15), матрица (20), внедрение и проверка (25), детекты (10), отчёт (10).
