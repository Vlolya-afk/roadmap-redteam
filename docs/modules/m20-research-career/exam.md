# Контрольная M20 — research и карьера

> Время: 🟢 60 мин · 🟡 4 ч · 🔴 8 ч. Сдаётся в `labs/m20-research-career/exam/`.

## 🟢 Задача 1. Research-note (60 мин)

**Дано:** любая лаборатория курса.

**Задание:**
1. Сформулируйте гипотезу.
2. Опишите стенд и метод.
3. Проведите 3 прогона.
4. Оформите результаты и ограничения.
5. Сделайте вывод.

**Сдать:** `note.md`, `data/`.

**Критерии:** гипотеза (20), метод (25), данные (25), вывод (20), оформление (10).

---

## 🟡 Задача 2. Инструмент (4 ч)

**Дано:** идея из вашей практики.

**Задание:**
1. Реализуйте MVP.
2. Напишите 3+ теста.
3. Оформите README.
4. Настройте CI.
5. Проверьте на реальных данных.

**Сдать:** репозиторий + `report.md`.

**Критерии:** функциональность (30), тесты (25), README (20), CI (15), качество (10).

---

## 🔴 Задача 3. Публикация + карьера (8 ч)

**Дано:** ваши материалы.

**Задание:**
1. Напишите writeup (2–3 стр.) по одной из лабораторий.
2. Подготовьте CFP-заявку.
3. Соберите портфолио (3 проекта).
4. Составьте матрицу компетенций.
5. Напишите план на 12 месяцев.
6. Проведите ревью: пробелы, риски, метрики.

**Сдать:** `public/`, `career/` — `writeup.md`, `cfp.md`, `portfolio.md`, `matrix.md`, `plan.md`.

**Критерии:** writeup (25), CFP (15), портфолио (20), матрица (20), план (20).
