# Контрольная M03 — код

> Время: 🟢 60 мин · 🟡 3 ч · 🔴 5–6 ч. Сдаётся в `labs/m03-scripting/exam/`.

## 🟢 Задача 1. Парсер логов (60 мин)

**Дано:** `/var/log/auth.log` (или синтетический лог на 10 000 строк).

**Задание:**
1. Посчитайте количество Failed и Accepted по IP.
2. Выведите топ-5 IP по Failed за последний час.
3. Найдите IP, у которого после 5+ Failed был Accepted (возможный подбор).
4. Сохраните результат в CSV и JSON.

**Сдать:** `logparse.py`, `report.csv`, `report.json`, `README.md`.

**Критерии:** корректность (40), обработка ошибок (20), CLI (20), README (20).

---

## 🟡 Задача 2. Сканер с отчётом (3 ч)

**Дано:** подсеть `10.10.10.0/24` (только свои ВМ).

**Задание:**
1. Напишите сканер на Python: диапазон портов, таймаут, пул потоков.
2. Для открытых портов сделайте banner grab (где возможно) и определите сервис по баннеру.
3. Вывод — таблица + JSON; `--help`; код возврата 0/1.
4. Добавьте 3 unit-теста (можно на localhost-сокете).
5. README: ограничения, этика, пример запуска.

**Сдать:** `scanner/` с кодом, тестами и README.

**Критерии:** работает (35), качество кода (20), тесты (20), отчёт/README (15), OPSEC (10).

## 🔴 Задача 3. Реверс и патч (5–6 ч)

**Дано:** `crackme_stripped` (соберите из исходника в уроке 3.4 с `-O2 -s`), пароль неизвестен.

**Задание:**
1. Определите пароль без запуска «в лоб»: `strings`, `objdump`, `gdb`, `ltrace`.
2. Опишите алгоритм проверки по дизассемблеру (какие регистры, сравнения, ветвления).
3. Сделайте патч бинарника, чтобы он принимал любой пароль (минимум — изменить условный переход), и докажите, что работает.
4. Объясните, какие защиты (canary/NX/PIE/ASLR) здесь есть и почему они не мешают реверсу.
5. Оформите `writeup.md` с командами и скриншотами.

**Сдать:** `reversing/` — `analysis.md`, `patched`, `patch.py` (или diff), `writeup.md`.

**Критерии:** пароль найден (25), разбор ассемблера (25), патч (20), защиты (15), оформление (15).
