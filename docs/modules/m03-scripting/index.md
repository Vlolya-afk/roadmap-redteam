# M03 — Python, Bash, Git

> **Этап 0 · 4 занятия · ~16 часов · артефакты в `labs/m03-scripting/`**

## Зачем этот модуль

Red teamer без кода — это оператор чужого инструмента. Свой скрипт нужен, когда готовый не решает задачу, а «поставить библиотеку» — когда нужно понять, что делает эксплойт. Плюс Git: без него нет портфолио.

## Чему научитесь

- Писать Python-скрипты на 100–200 строк с аргументами и ошибками.
- Делать сетевые запросы, сканеры и парсеры логов.
- Вести репозиторий так, чтобы его не стыдно показать.
- Читать чужой C-код и понимать, где искать пароль/уязвимость.

## Критерии выхода

- [ ] Ваш скрипт запускается с `--help` и не падает на кривом вводе.
- [ ] Вы понимаете, что такое `try/except/finally` и зачем `with`.
- [ ] В репозитории нет секретов, есть README и осмысленная история коммитов.
- [ ] Можете найти пароль в простом crackme без исходников.
- [ ] Объясняете, что такое стек и почему переполнение буфера опасно.

## Совет

Не учите Python «по книге до конца». Учите под задачу: парсер логов → сканер → API-клиент. Каждый урок — рабочий инструмент, а не упражнение ради упражнения.
