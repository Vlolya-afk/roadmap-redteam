# Контрольная M10 — повышение привилегий

> Время: 🟢 60 мин · 🟡 3 ч · 🔴 6 ч. Сдаётся в `labs/m10-privesc/exam/`.

## 🟢 Задача 1. Linux-чеклист (60 мин)

**Дано:** обычный пользователь `bob` на `LNX01`.

**Задание:**
1. Пройдите чек-лист: `sudo -l`, SUID, cron, capabilities, writable-файлы, PATH, сервисы.
2. Найдите минимум 2 потенциальных пути.
3. Для каждого объясните механизм и предусловие.
4. Не эксплуатируйте — только гипотезы.

**Сдать:** `linux-checklist.md` + `evidence/`.

**Критерии:** полнота (40), корректность гипотез (40), оформление (20).

---

## 🟡 Задача 2. Служба Windows (3 ч)

**Дано:** `WIN01`, пользователь `alice` в группе `Users`, служба с `SERVICE_CHANGE_CONFIG` для `Users`.

**Задание:**
1. Подтвердите слабые права через `sc`/`accesschk`.
2. Измените `binPath` и получите `SYSTEM`.
3. Докажите уровень привилегий.
4. Соберите события 4688/7045 за время атаки.
5. Опишите фикс и проверьте его на снимке.

**Сдать:** `win-service/` — `steps.md`, `evidence/`, `detection.md`, `fix.md`.

**Критерии:** эксплуатация (35), доказательство (20), детект (25), фикс (20).

---

## 🔴 Задача 3. Цепочка с кред-дампом (6 ч)

**Дано:** `WIN01` + `DC01`.

**Задание:**
1. Получите foothold под непривилегированным пользователем.
2. Повысьте привилегии до локального администратора.
3. Сдампьте LSASS и SAM, извлеките материал.
4. Переиспользуйте его по SMB (PtH) или Kerberos.
5. Составьте карту: какие учётки скомпрометированы и что это даёт.
6. Для каждого шага укажите событие/лог и способ фикса.
7. Предложите план реагирования: что делать в первые 24 часа.

**Сдать:** `chain/` — `writeup.md`, `timeline.md`, `detection.md`, `response.md`, `evidence/`.

**Критерии:** цепочка (30), креды (20), движение (15), детект (20), реагирование (15).
