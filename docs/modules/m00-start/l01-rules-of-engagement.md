# 0.1 — Этика, закон, scope и изоляция

> **M00 · Этап 0 · 3 ч · 🟢 база · артефакт:** `labs/m00-start/l01-rules/`

## Цель

Зафиксировать границы: что можно в лаборатории, что нельзя никогда, и как технически доказать, что стенд изолирован.

## Результат

- Заполненный RoE для вашей учебной лаборатории.
- Скрин/лог, доказывающий отсутствие bridged-трафика.
- Понимание статей 272, 273, 274 УК РФ и разницы между «своя ВМ» и «чужой сайт».

## Теория

- Разрешение важнее навыка: доступ без согласия — преступление, даже если «ничего не менял».
- Легальные контуры: своя лаборатория, bug bounty в scope, пентест по договору. Всё остальное — нет.
- Bridged-адаптер = ваша ВМ в одной сети с домашними устройствами и соседями. Host-only = изолированная подсеть.
- Снапшот — не бэкап, а точка возврата. Бэкап хоста всё равно нужен.
- OPSEC начинается с гигиены данных: никаких реальных паролей, почт и имён в лабах.
- «Проверить сайт друга/конкурента за деньги» — это не подработка, а состав преступления.

## Лаборатория

### 1. Написать RoE

Скопируйте шаблон из [этики и закона](../../ethics-legal.md#rules-of-engagement-roe--шаблон) в `labs/m00-start/l01-rules/roe.md`. Заполните: стороны (вы и вы), scope `10.10.10.0/24`, `192.168.56.0/24`, окно работ, запрещённые техники (DoS, атаки на хост), обработка данных.

Ожидаемо: документ на 1 страницу, где явно написано «вне scope — всё, кроме перечисленного».

### 2. Проверить сетевую изоляцию

На хосте и в атакующей ВМ:

```bash
ip -brief addr
ip route
```

Ожидаемо в ВМ: два интерфейса — `192.168.56.10/24` (VMnet1) и, если нужен интернет, `192.168.150.x/24` (VMnet8). **Не должно быть** адреса вашей домашней сети `192.168.0.0/24` или `192.168.1.0/24`.

Проверка трафика наружу:

```bash
sudo tcpdump -i any -n 'not net 10.10.10.0/24 and not net 192.168.56.0/24 and not port 53' -c 20
```

Ожидаемо: либо пусто, либо только NAT-трафик на обновления. Если видите ARP/DHCP от домашней сети — у ВМ включён bridged, выключите немедленно.

### 3. Проверить, что вы видите только свои цели

```bash
sudo nmap -sn 10.10.10.0/24
sudo nmap -sn 192.168.56.0/24
```

Ожидаемо: только ваши ВМ. Если в списке устройства, которых вы не создавали, — стоп, разберитесь с адаптером.

### 4. Зафиксировать артефакт

```bash
mkdir -p labs/m00-start/l01-rules
{ ip -brief addr; echo ---; ip route; echo ---; sudo nft list ruleset; } \
  > labs/m00-start/l01-rules/isolation-check.txt
```

## Атака и защита

- **В реальной операции:** выход за scope — худшее, что может случиться с red teamer. Это потеря контракта, репутации и иногда свободы.
- **Детект:** blue-команда видит сканы из неожиданной подсети и эскалирует. Вы должны быть в состоянии доказать, что это вы и что это в scope.
- **Фикс:** письменный RoE, deconfliction-контакт, логирование всех действий с таймстампами.
