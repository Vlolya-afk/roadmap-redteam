# M00 — Старт, лаборатория, правила игры

> **Этап 0 · 3 занятия · ~10 часов · артефакты в `labs/m00-start/`**

## Зачем этот модуль

До первой команды `nmap` нужно три вещи: понимать, где граница законности, иметь работающую изолированную лабораторию и уметь её восстанавливать. Пропущенный M00 — самая частая причина, по которой трек заканчивается удалением виртуалок и «анонимным» сканом чужого сайта.

## Чему научитесь

- Формулировать scope и RoE так, чтобы не было вопросов ни у вас, ни у юриста.
- Ставить Arch Linux вручную и чинить загрузчик.
- Строить сети VMware host-only, считать бюджет RAM и откатывать снапшоты.
- Проверять изоляцию лаборатории технически, а не «на глаз».

## Критерии выхода

- [ ] Можете с нуля поднять Arch в ВМ и восстановить загрузчик с live-ISO.
- [ ] В лаборатории нет bridged-адаптеров, это подтверждено `tcpdump` и `ip a`.
- [ ] Есть снапшоты `clean-install` у всех ВМ и вы умеете откатывать за 2 минуты.
- [ ] Написан и подписан RoE для учебной лаборатории.
- [ ] `free -h` при трёх включённых ВМ показывает ≥ 2 ГБ свободных.

## Если что-то пошло не так

- Arch не грузится → раздел 10 в [инструкции](../../lab/arch-install.md).
- ВМ не пингуются → [диагностика VMware](../../lab/vmware-topology.md#диагностика).
- Страшно начинать → поставьте Arch **второй ВМ**, не на железо. Ничего не потеряете.
