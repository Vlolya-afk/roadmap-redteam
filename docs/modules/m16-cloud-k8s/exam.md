# Контрольная M16 — cloud и Kubernetes

> Время: 🟢 90 мин · 🟡 4 ч · 🔴 8 ч. Сдаётся в `labs/m16-cloud-k8s/exam/`.

## 🟢 Задача 1. IAM-карта (90 мин)

**Дано:** учебный AWS-аккаунт/LocalStack.

**Задание:**
1. Определите текущего principal.
2. Соберите пользователей, роли, политики.
3. Найдите 3 опасных права.
4. Опишите потенциальный путь эскалации.
5. Укажите события CloudTrail.

**Сдать:** `iam-map.md`, `paths.md`, `events.md`.

**Критерии:** инвентаризация (30), права (30), путь (25), детект (15).

---

## 🟡 Задача 2. K8s SA abuse (4 ч)

**Дано:** локальный кластер `k3d`.

**Задание:**
1. Найдите over-permissioned SA.
2. Получите токен.
3. Прочитайте секрет.
4. Создайте pod с hostPath (если разрешено).
5. Соберите audit/event log.
6. Опишите фикс.

**Сдать:** `k8s/` — `steps.md`, `evidence/`, `detection.md`, `fix.md`.

**Критерии:** SA (25), доступ (25), escape (20), детект (15), фикс (15).

---

## 🔴 Задача 3. Cloud-цепочка + детект (8 ч)

**Дано:** AWS free tier + локальный K8s.

**Задание:**
1. Постройте цепочку: IAM → роль → ресурс (или K8s → SA → секрет).
2. Сохраните доказательства.
3. Настройте 3 детекта (CloudTrail/GuardDuty/Falco).
4. Проверьте, что детекты срабатывают.
5. Опишите, что не сработало.
6. Дайте рекомендации: least privilege, boundaries, admission.
7. Оформите отчёт.

**Сдать:** `chain/` — `writeup.md`, `evidence/`, `detections/`, `gaps.md`, `report.md`.

**Критерии:** цепочка (30), детекты (25), проверка (20), рекомендации (15), отчёт (10).
