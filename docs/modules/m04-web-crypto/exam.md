# Контрольная M04 — web

> Время: 🟢 60 мин · 🟡 3 ч · 🔴 6–8 ч. Сдаётся в `labs/m04-web-crypto/exam/`.

## 🟢 Задача 1. DVWA low (60 мин)

**Дано:** DVWA, security `low`.

**Задание:**
1. Эксплуатируйте 4 уязвимости: SQLi, reflected XSS, command injection, LFI.
2. Для каждой приведите запрос, payload, вывод-доказательство.
3. Объясните причину в одну строку и фикс в одну строку.

**Сдать:** `low.md` + скриншоты (без реальных данных).

**Критерии:** 4/4 (60), объяснение (20), фиксы (20).

---

## 🟡 Задача 2. Medium и Juice Shop (3 ч)

**Дано:** DVWA security `medium`, Juice Shop.

**Задание:**
1. Обойдите фильтры medium минимум в 3 уязвимостях, опишите, что именно фильтруется.
2. В Juice Shop найдите 3 задачи (например, IDOR в корзине, XSS, weak password) и оформите.
3. Для каждой — remediation.

**Сдать:** `medium.md`, `juice.md`, `evidence/`.

**Критерии:** обходы (40), Juice Shop (30), remediation (20), оформление (10).

---

## 🔴 Задача 3. Полный web-отчёт (6–8 ч)

**Дано:** Juice Shop (или crAPI), доступ по HTTP.

**Задание:**
1. Проведите ограниченный по времени ассессмент (4 часа чистой работы).
2. Найдите минимум 6 уязвимостей разных классов.
3. Для каждой: CVSS 3.1 (обоснованный), PoC, влияние на бизнес, remediation, retest-план.
4. Отдельный раздел — TLS/заголовки безопасности локального сервера.
5. Executive summary на 1 страницу для не-технического читателя.

**Сдать:** `report.md` (10–15 страниц), `findings/`, `poc/`, `retest.md`.

**Критерии:** находки и PoC (30), CVSS и приоритизация (20), remediation (20), executive summary (15), оформление (15).
