# Контрольная M17 — detection engineering

> Время: 🟢 90 мин · 🟡 4 ч · 🔴 8 ч. Сдаётся в `labs/m17-detection/exam/`.

## 🟢 Задача 1. Телеметрия (90 мин)

**Дано:** `WIN01`, `LNX01`.

**Задание:**
1. Настройте Sysmon и auditd.
2. Сгенерируйте 5 действий.
3. Соберите события по каждому.
4. Найдите 3 пробела в телеметрии.
5. Предложите, как их закрыть.

**Сдать:** `telemetry.md`, `events/`, `gaps.md`.

**Критерии:** настройка (30), события (30), пробелы (25), решения (15).

---

## 🟡 Задача 2. Sigma + SIEM (4 ч)

**Дано:** Wazuh/ELK, логи.

**Задание:**
1. Напишите 3 Sigma-правила.
2. Конвертируйте под свой SIEM.
3. Подключите и проверьте.
4. Соберите FP на baseline.
5. Опишите тюнинг.

**Сдать:** `sigma/`, `siem/`, `tuning.md`.

**Критерии:** правила (35), конвертация (20), проверка (25), тюнинг (20).

---

## 🔴 Задача 3. Purple-цикл (8 ч)

**Дано:** лаборатория M17.

**Задание:**
1. Выберите 5 техник ATT&CK.
2. Выполните (Atomic/вручную).
3. Для каждой: видно/не видно, какое событие.
4. Напишите правила для 3.
5. Проверьте на атаке и baseline.
6. Измерьте MTTD и FP.
7. Постройте матрицу покрытия.
8. Напишите план на следующий цикл.

**Сдать:** `purple/` — `techniques.md`, `rules/`, `metrics.md`, `coverage.md`, `next.md`.

**Критерии:** техники (20), наблюдение (20), правила (25), метрики (20), план (15).
