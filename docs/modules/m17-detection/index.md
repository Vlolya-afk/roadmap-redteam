# M17 — Detection engineering / purple

> **Этап 3 · 4 занятия · ~20 часов · артефакты в `labs/m17-detection/`**

## Зачем этот модуль

Red team без детекта — это половина работы. Senior понимает, что видит защитник, и умеет превращать атаку в правило, тест и метрику.

## Чему научитесь

- Собирать телеметрию: Sysmon, auditd, EDR, PowerShell.
- Писать Sigma-правила и проверять их.
- Поднимать SIEM (Wazuh/ELK) и настраивать алерты.
- Замыкать purple loop: атака → детект → правило → ретест.
