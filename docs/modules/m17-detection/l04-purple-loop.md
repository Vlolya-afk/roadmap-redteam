# 17.4 — Purple loop

> **M17 · Этап 3 · 5 ч · 🔴 · артефакт:** `labs/m17-detection/l04-purple/`

## Цель

Замкнуть цикл: атака → наблюдение → правило → тест → улучшение. Научиться измерять, а не верить.

## Результат

- 3 полных цикла.
- Матрица покрытия.
- Метрики MTTD/FP.

## Теория

### 1. Цикл

```text
Выбрать технику → выполнить → собрать логи → понять, видно ли
→ написать правило → проверить на атаке и baseline → измерить → повторить
```

### 2. Atomic Red Team

Библиотека атомарных тестов:

```bash
git clone https://github.com/redcanaryco/atomic-red-team.git
# Invoke-AtomicTest T1003.001 -TestNumbers 1
```

Каждый тест — конкретная техника. Удобно для покрытия.

### 3. Detection-as-code

- Правила в git.
- CI: линт, конвертация, тест.
- Версионирование.
- Ревью.

### 4. Метрики

- **Coverage:** доля техник с правилом.
- **MTTD:** время от действия до алерта.
- **FP rate:** ложные/все.
- **Действия:** сколько алертов закрыто.

### 5. Ошибки

- Правило «на всё».
- Нет baseline.
- Нет владельца.
- Нет ретеста.
- Метрики ради метрик.
