# 6.3 — Активный recon

> **M06 · Этап 1 · 4 ч · 🟡 · артефакт:** `labs/m06-recon/l03-active/`

## Цель

Научиться аккуратно сканировать свою лабораторию: находить хосты, сервисы, версии и скрытые пути, не устраивая шум и не ломая цели.

## Результат

- `nmap`-отчёт по `10.10.10.0/24` с версиями.
- Найденные web-пути и vhost через `ffuf`.
- Понимание, какой скан что оставляет в логах.

## Теория

- `-sn` — ping sweep, `-sS` — SYN, `-sT` — connect, `-sU` — UDP.
- `-sV` — версии, `-sC` — дефолтные скрипты, `-O` — ОС (осторожно, врёт в ВМ).
- `--script` — NSE; `vuln`-категория шумная и может ломать сервисы.
- `ffuf`/`gobuster` — перебор путей и vhost; скорость и коды ответов.
- `whatweb` — технологии по заголовкам/HTML.
- Активный скан виден в логах и IDS; в реальном проекте — только в согласованное окно.

## Лаборатория

### 1. Хосты

```bash
sudo nmap -sn 10.10.10.0/24
ip neigh
```

Ожидаемо: DC01, WS01, LNX01, attacker. Сравните с `ip neigh` — ARP-таблица подтверждает L2-соседей.

### 2. Порты и версии

```bash
sudo nmap -sS -sV -p- --min-rate 1000 10.10.10.30 -oA active/lnx01
sudo nmap -sV -sC -p 22,80,443,445,3389 10.10.10.10 10.10.10.20
```

Ожидаемо: открытые порты, версии (`OpenSSH 9.x`, `nginx`, `Samba`), скрипты (`http-title`, `smb-os-discovery`).

Обратите внимание на время: `-p-` по 65k портов занимает минуты. В отчёте фиксируйте параметры.

### 3. Web-пути

```bash
paru -S seclists   # или git clone https://github.com/danielmiessler/SecLists
ffuf -u http://10.10.10.30/FUZZ \
  -w /usr/share/seclists/Discovery/Web-Content/common.txt \
  -mc 200,204,301,302,403 -t 40
```

Ожидаемо: список путей (`/admin`, `/backup`, `/login.php`). Для DVWA:

```bash
ffuf -u http://127.0.0.1:8080/FUZZ \
  -w /usr/share/seclists/Discovery/Web-Content/common.txt -mc 200,301,302
```

### 4. Vhost

```bash
printf 'dev\nstaging\nadmin\napi\n' > active/vhosts.txt
ffuf -u http://10.10.10.30 -H "Host: FUZZ.lab.local" \
  -w active/vhosts.txt -fs 0
```

Ожидаемо: либо все ответы одинаковы (нет vhost), либо отличаются по размеру. Настройте виртуальный хост в nginx, чтобы увидеть разницу.

### 5. Технологии

```bash
whatweb -a 3 http://10.10.10.30
curl -s -I http://10.10.10.30 | head
```

Ожидаемо: сервер, язык, заголовки. Запишите, что можно проверить дальше.

## Атака и защита

- **Атака:** перебор путей находит забытые админки и бэкапы; версии — основа для CVE.
- **Детект:** всплеск 404, много запросов с одного IP, `nmap`-сигнатуры, WAF-алерты.
- **Фикс:** rate limiting, WAF, скрытие версий, удаление бэкапов, 404 на всё лишнее.
