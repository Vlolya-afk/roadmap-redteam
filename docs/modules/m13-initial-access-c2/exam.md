# Контрольная M13 — initial access и C2

> Время: 🟢 60 мин · 🟡 4 ч · 🔴 8 ч. Сдаётся в `labs/m13-initial-access-c2/exam/`.

## 🟢 Задача 1. Инфраструктурная схема (60 мин)

**Дано:** тестовый домен `training.lab`, `LNX01`, `WIN01`.

**Задание:**
1. Нарисуйте схему: DNS → TLS → landing → redirector → C2.
2. Для каждого компонента укажите роль, риск и детект.
3. Составьте список IOC.
4. Определите, что можно убрать без потери функциональности.

**Сдать:** `scheme.md`, `ioc.md`.

**Критерии:** схема (40), детект (30), IOC (20), минимизация (10).

---

## 🟡 Задача 2. Доставка и C2 (4 ч)

**Дано:** `LNX01`, `WIN01`, изолированная сеть.

**Задание:**
1. Поднимите landing-страницу и lure.
2. Доставьте implant через HTTP.
3. Получите сессию Sliver.
4. Настройте nginx-редиректор с фильтром по UA.
5. Соберите `tcpdump` и логи nginx.
6. Опишите 3 признака, по которым защитник найдёт канал.

**Сдать:** `delivery/` — `steps.md`, `pcap/`, `logs/`, `detection.md`.

**Критерии:** доставка (25), C2 (25), редиректор (25), детект (25).

---

## 🔴 Задача 3. Полная операция с burn-планом (8 ч)

**Дано:** лабораторный домен, `WIN01`, `DC01` (только для проверки доступа), `LNX01`.

**Задание:**
1. Спланируйте операцию: цель, RoE, окно, техники, инфраструктура.
2. Реализуйте фишинг + доставку + C2.
3. Получите сессию и выполните 3 команды.
4. Настройте редиректор и профиль.
5. Ведите таймлайн и IOC-лист.
6. Напишите burn-план с 4 триггерами.
7. Проведите уборку и докажите, что артефакты удалены.
8. Оформите отчёт: что сработало, что нет, что бы изменили.

**Сдать:** `operation/` — `plan.md`, `timeline.md`, `ioc.md`, `burn-plan.md`, `cleanup.md`, `report.md`, `evidence/`.

**Критерии:** план (15), реализация (25), OPSEC (20), детект (15), уборка (10), отчёт (15).
