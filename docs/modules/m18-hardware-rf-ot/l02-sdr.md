# 18.2 — SDR и разбор сигналов

> **M18 · Этап 3 · 6 ч · 🔴 · артефакт:** `labs/m18-hardware-rf-ot/l02-sdr/`

## Цель

Понять, как принять и разобрать радиосигнал: частота, модуляция, полоса, демодуляция — на примере легальных сигналов (ADS-B, метео, FM).

## Результат

- Принятый и записанный сигнал.
- Спектрограмма и разбор модуляции.
- Понимание, где заканчивается «приём» и начинается «передача» (и закон).

## Теория

### 1. Основы

- **Частота** — где сигнал (Hz).
- **Полоса** — сколько занимает.
- **Модуляция** — AM/FM/FSK/PSK/QAM.
- **Усиление** — чувствительность.
- **Sample rate** — сколько отсчётов в секунду.

### 2. RTL-SDR

Дешёвый приёмник (24–1766 MHz). Не передаёт. Для передачи нужен HackRF (и разрешение).

```bash
rtl_test -t
rtl_fm -f 100.0M -M wbfm -s 200000 -r 48000 | aplay -r 48000 -f S16_LE
```

Ожидаемо: FM-радио.

### 3. GQRX/GNU Radio

- GQRX — визуальный приём.
- GNU Radio — граф обработки.
- `inspectrum`/`Universal Radio Hacker` — разбор записей.

### 4. ADS-B

```bash
rtl_adsb -V
```

Ожидаемо: сообщения самолётов. Легально принимать.

### 5. Запись и анализ

```bash
rtl_sdr -f 433.92M -s 2048000 capture.iq
# затем inspectrum capture.iq -r 2048000
```

Ожидаемо: IQ-файл и спектрограмма.

### 6. Передача и закон

- Приём — почти всегда легален.
- Передача — только в разрешённых полосах, с лицензией или малой мощностью (LPD/PMR в рамках правил).
- Глушение, спуфинг, перехват чужих данных — незаконны.
- Не передавайте на частотах авиации, скорой, полиции.

## Лаборатория

> RTL-SDR (или приёмник) + антенна. Только приём.

### 1. Проверка

```bash
rtl_test -t
```

Ожидаемо: устройство найдено.

### 2. FM

```bash
rtl_fm -f 100.0M -M wbfm -s 200000 -r 48000 | aplay -r 48000 -f S16_LE
```

Ожидаемо: звук.

### 3. ADS-B

```bash
rtl_adsb -V
```

Ожидаемо: сообщения.

### 4. Запись 433 MHz

```bash
rtl_sdr -f 433.92M -s 2048000 -n 2048000 capture.iq
```

Ожидаемо: файл ~2 МБ за секунду.

### 5. Спектрограмма

Откройте в `inspectrum`/`URH`. Найдите всплески. Опишите модуляцию (если видно).
