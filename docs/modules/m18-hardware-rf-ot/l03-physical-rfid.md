# 18.3 — Физическая безопасность и RFID

> **M18 · Этап 3 · 5 ч · 🟡 · артефакт:** `labs/m18-hardware-rf-ot/l03-physical/`

## Цель

Оценить физический периметр и RFID-доступ: как работает карта, что можно прочитать, как защититься.

## Результат

- Чеклист физической оценки.
- Чтение/клонирование собственной карты (в лабе).
- Отчёт с рекомендациями.

## Теория

### 1. Физический периметр

- Турникеты, двери, ресепшн.
- Tailgating/piggybacking.
- Камеры, охрана, журналы.
- Мусор (dumpster diving) — легально не везде.
- Социальная инженерия на входе.

### 2. RFID/NFC

| Тип | Частота | Пример | Защита |
|---|---|---|---|
| EM4100 | 125 kHz | старые карты | нет |
| MIFARE Classic | 13.56 MHz | проездные, СКУД | Crypto1 (сломан) |
| MIFARE DESFire | 13.56 MHz | современные | AES |
| HID iCLASS | 13.56 MHz | СКУД | зависит |
| NFC (телефон) | 13.56 MHz | платежи | токенизация |

### 3. Инструменты

- **Proxmark3** — чтение/клонирование/эмуляция.
- **Flipper Zero** — 125 kHz, NFC, Sub-GHz (только свои устройства).
- **ACR122U** — NFC-ридер.
- **mifareuk**/`mfoc` — атаки на Classic.

### 4. Клонирование (в лабе)

```bash
# Proxmark3
hf search
hf mf autopwn
hf mf dump
```

Ожидаемо: дамп своей карты. Клонирование — только своей.

### 5. Защита

- DESFire/EV2, шифрование.
- Двухфакторный доступ (карта + PIN).
- Мониторинг аномалий (одна карта в двух местах).
- Обучение сотрудников tailgating.
- Защита от клонирования: secure element, challenge-response.

## Атака и защита

- **Атака:** клонирование, tailgating.
- **Детект:** журналы СКУД, аномалии, камеры.
- **Фикс:** современные карты, PIN, мониторинг, обучение.
