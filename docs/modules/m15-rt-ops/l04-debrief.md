# 15.4 — Debrief и purple feedback

> **M15 · Этап 2 · 4 ч · 🟡 · артефакт:** `labs/m15-rt-ops/l04-debrief/`

## Цель

Превратить операцию в улучшение защиты: провести debrief, собрать purple-фидбек и зафиксировать action items.

## Результат

- Протокол debrief.
- 5 action items с владельцами и сроками.
- 2–3 правила детекта.

## Теория

### 1. Debrief

Участники: red team, blue team, IT, владелец риска. Формат:

1. Что планировали.
2. Что получилось.
3. Что не получилось и почему.
4. Что увидел blue team.
5. Что улучшить.

Правило: без обвинений, фокус на системе.

### 2. Purple feedback

Red team отдаёт blue team:

- технику;
- артефакты (лог, событие);
- правило детекта (Sigma);
- тест-кейс.

Blue team проверяет правило на тех же данных и подтверждает.

### 3. Action items

Хороший action item: конкретный, измеримый, с владельцем и сроком.

Плохо: «улучшить мониторинг».
Хорошо: «добавить Sigma-правило на Kerberoasting, проверить на данных за 30 дней, владелец — SOC lead, срок — 2 недели».

### 4. Метрики

- Время до детекта.
- Время до реакции.
- Доля техник, покрытых правилами.
- Число action items, закрытых за спринт.

### 5. Документация

Протокол, решения, owners, сроки — в общий трекер. Иначе debrief превращается в разговор.

## Лаборатория

> Используйте операцию из M15.2–15.3.

### 1. Протокол

Соберите встречу (можно solo, с ролями). Заполните протокол по 5 пунктам.

### 2. Маппинг

Для каждой техники: что видел blue team, какое событие, какое правило есть/нет.

| Техника | Событие | Правило | Покрытие |
|---|---|---|---|

### 3. Sigma

Напишите 2 правила на основе ваших действий. Пример:

```yaml
title: Kerberoasting RC4 TGS Request
logsource:
  product: windows
  service: security
detection:
  selection:
    EventID: 4769
    TicketEncryptionType: '0x17'
  condition: selection
level: medium
```

### 4. Action items

5 пунктов с owner/сроком/критерием готовности.

### 5. Проверка

Прогоните правила на собранных логах. Ожидаемо: срабатывают на вашу атаку и не срабатывают на baseline.

## Атака и защита

- **Атака:** (фидбек) сделать защиту сильнее.
- **Детект:** правила + тест-кейсы.
- **Фикс:** action items, ретест через месяц.
