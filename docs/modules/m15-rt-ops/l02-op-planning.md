# 15.2 — Планирование операции и MITRE

> **M15 · Этап 2 · 5 ч · 🟡 · артефакт:** `labs/m15-rt-ops/l02-plan/`

## Цель

Спланировать операцию как проект: цели, гипотезы, техники, ресурсы, риски, метрики — с маппингом на MITRE ATT&CK.

## Результат

- План операции на 2–3 страницы.
- Матрица техник ATT&CK.
- Список гипотез о детекте.

## Теория

### 1. Цели операции

Не «получить DA», а бизнес-цель: «проверить, может ли внешний атакующий добраться до финансовых данных». Технические цели — шаги к ней.

### 2. Этапы

1. **Recon** — что известно.
2. **Initial access** — вектор.
3. **Foothold** — закрепление.
4. **Privesc** — права.
5. **Lateral** — движение.
6. **Objective** — доступ к данным/системам.
7. **Exfil/impact** — только если разрешено.

### 3. MITRE ATT&CK

Маппинг техник: `T1566` phishing, `T1078` valid accounts, `T1059` command interpreter, `T1003` OS credential dumping, `T1021` remote services, `T1071` application layer protocol.

Матрица:

| Этап | Техника | ID | Инструмент | Детект-гипотеза |
|---|---|---|---|---|

### 4. Гипотезы

«Если мы сделаем X, SOC увидит Y в течение Z». Это превращает операцию в эксперимент, а не в демонстрацию.

### 5. Риски

- Технические: уронить сервис, заблокировать аккаунт.
- Организационные: утечка, конфликт с IT.
- Юридические: выход за scope.
- OPSEC: засветить инфраструктуру.

Для каждого — вероятность, влияние, митигация.

### 6. Метрики

- Время до первого детекта.
- Время до реакции.
- Покрытие техник.
- Количество пропущенных техник.
- Качество отчёта.

- **Фикс:** по результатам — правила и hardening.
