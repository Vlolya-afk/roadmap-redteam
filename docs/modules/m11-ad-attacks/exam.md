## 🟢 Задача 1. BloodHound-путь (90 мин)

**Дано:** `lab.local`, пользователь `alice`.

**Задание:**
1. Соберите граф (`DCOnly,ACL`).
2. Отметьте `alice` как owned.
3. Найдите кратчайший путь к `Domain Admins`.
4. Опишите каждый шаг: объект, право, что даёт.
5. Предложите фикс для самого слабого звена.

**Сдать:** `path.md`, скриншоты, `fix.md`.

**Критерии:** сбор (20), путь (30), разбор шагов (30), фикс (20).

## 🟡 Задача 2. Kerberoasting + ACL (4 ч)

**Дано:** `lab.local`, `alice`, сервисный аккаунт с SPN и слабым паролем.

**Задание:**
1. Найдите Kerberoastable-аккаунты.
2. Получите TGS и восстановите пароль офлайн.
3. Используйте аккаунт для доступа к SMB/WinRM.
4. Через ACL (`GenericAll`/`WriteDACL`) получите членство в привилегированной группе.
5. Соберите события 4769 и 5136 за время атаки.
6. Опишите фикс для обоих этапов.

**Сдать:** `kerb-acl/` — `steps.md`, `evidence/`, `detection.md`, `fix.md`.

**Критерии:** Kerberoasting (25), доступ (15), ACL (25), детект (20), фикс (15).

## 🔴 Задача 3. Полная цепочка до Domain Admin (8 ч)

**Дано:** `lab.local`, `DC01`, `WIN01`, `WIN02`, ADCS с ESC1.

**Задание:**
1. Foothold под `alice`.
2. Enumeration и карта путей.
3. Получите локального админа на `WIN01`.
4. Через delegation/ADCS/ACL дойдите до `Domain Admin`.
5. Докажите доступ (`ntds.dit` или `secretsdump`).
6. Для каждого шага: событие, лог, фикс.
7. Напишите executive summary и технический отчёт.
8. Предложите план реагирования и containment.

**Сдать:** `chain/` — `writeup.md`, `timeline.md`, `detection.md`, `report.md`, `response.md`, `evidence/`.

**Критерии:** цепочка (30), техника (20), детект (20), отчёт (15), реагирование (15).
