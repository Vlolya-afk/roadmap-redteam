# Контрольная M05 — Windows/AD

> Время: 🟢 90 мин · 🟡 3–4 ч · 🔴 6–8 ч. Сдаётся в `labs/m05-windows-ad/exam/`.

## 🟢 Задача 1. Домен с нуля (90 мин)

**Дано:** чистый Windows Server Evaluation, 4 ГБ RAM.

**Задание:**
1. Поднимите DC `lab.local` со статическим IP и DNS.
2. Создайте OU `Staff`, `Workstations`, `Servers`, `ServiceAccounts`.
3. Создайте 5 пользователей и 2 группы (`Helpdesk`, `Finance`) с членством.
4. Создайте `svc_sql` с SPN и `svc_backup` без preauth.
5. Присоедините WS01 к домену.
6. Сделайте снапшот `domain-ready`.

**Сдать:** `build.md` с командами, `Get-ADDomain`, `setspn -L`, `klist`.

**Критерии:** DC и DNS (30), OU/пользователи/группы (25), сервисные учётки (25), WS в домене (20).

---

## 🟡 Задача 2. Уязвимая конфигурация и доказательство (3–4 ч)

**Дано:** домен из задачи 1.

**Задание:**
1. Создайте 4 уязвимости:
   - SPN на сервисной учётке со слабым паролем и RC4;
   - учётка без preauth;
   - `GenericAll` для `helpdesk` на OU;
   - `cpassword` в SYSVOL (демо-файл).
2. Для каждой докажите влияние **в своей лабе**: запросите TGS, AS-REP, измените объект через ACL, расшифруйте cpassword.
3. Для каждой укажите событие/лог, который это фиксирует.
4. Напишите `risk.md`: что получит атакующий на каждом шаге.

**Сдать:** `vuln-config.md`, `evidence/`, `risk.md`.

**Критерии:** 4/4 созданы и доказаны (50), события (25), анализ риска (25).

---

## 🔴 Задача 3. Харденинг AD (6–8 ч)

**Дано:** уязвимый домен из задачи 2.

**Задание:**
1. Составьте baseline из 12 проверок (ACL, сервисные учётки, Kerberos, GPO, SYSVOL, доверия, аудит).
2. Реализуйте минимум 4 исправления:
   - перевести сервис на gMSA или длинный пароль + AES;
   - включить preauth;
   - убрать `GenericAll`;
   - удалить cpassword и включить аудит.
3. Для каждого исправления покажите «до/после» и проверку.
4. Напишите 3 детекта (Sigma/Event ID) на оставшиеся риски.
5. Отчёт: 8–12 страниц, executive summary + technical.

**Сдать:** `hardening/` — `baseline.md`, `changes.ps1`, `before-after/`, `detections/`, `report.md`.

**Критерии:** baseline (20), исправления и проверка (30), детекты (20), отчёт (20), воспроизводимость (10).
