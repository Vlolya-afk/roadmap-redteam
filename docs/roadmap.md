# Дорожная карта: 0 → Senior (red team)

## Сначала — честно

«Senior» — это не набор инструментов. Это **способность самостоятельно довести задачу до результата и отвечать за решения**, когда данных не хватает. В red team это значит: спланировать операцию, выбрать TTP под цель, не спалиться, доказать риск, написать отчёт, который поймёт и CTO, и сисадмин, и не сломать продакшн.

Поэтому трек разделён на две неравные части:

- **Пройденное самостоятельно** (этапы 0–3): база, атакующие навыки, red team core, широта. Это ~30–38 месяцев при 10–12 ч/нед. Этого достаточно, чтобы претендовать на junior/middle red team и уверенно сдать OSCP/CRTO.
- **Добираемое работой** (этап 4): реальные операции, заказчики, инциденты, менторство, публичные исследования. 2–4 года. Именно здесь появляется senior.

Ниже — что именно считается выходом с каждого этапа.

## Этап 0. База (6–8 месяцев)

**Цель:** свободно жить в Linux, понимать сеть на уровне пакетов, читать и писать код, понимать web и Windows/AD.

| Модуль | Выход |
|---|---|
| [M00 Старт](modules/m00-start/index.md) | Работающая изолированная лаборатория, снапшоты, правила OPSEC |
| [M01 Linux](modules/m01-linux/index.md) | Ставить Arch с нуля, чинить сломанную систему, писать bash-скрипты |
| [M02 Сети](modules/m02-networking/index.md) | Читать pcap, объяснять путь пакета, настраивать подсети и NAT |
| [M03 Код](modules/m03-scripting/index.md) | Python-скрипт на 100–200 строк, git-репозиторий, чтение чужого кода |
| [M04 Web и крипто](modules/m04-web-crypto/index.md) | Понимать HTTP/TLS/PKI, поднять DVWA, объяснить OWASP Top 10 |
| [M05 Windows/AD](modules/m05-windows-ad/index.md) | Поднять домен, понимать NTLM/Kerberos/GPO/ACL |

**Критерий выхода:** вы можете с нуля поднять стенд, объяснить любой этап прохождения пакета от браузера до БД и показать 6+ артефактов в `labs/`.

**Типичная ошибка:** застрять на этапе 0 на год, переставляя дистрибутивы. Двигайтесь, как только лаба воспроизводится.

## Этап 2. Red team core (8–12 месяцев)

**Цель:** научиться работать в корпоративной среде: домен, защита, инфраструктура, скрытность, отчётность.

| Модуль | Выход |
|---|---|
| [M11 AD-атаки](modules/m11-ad-attacks/index.md) | BloodHound-путь, Kerberoasting, ACL, delegation, ADCS |
| [M12 Обход защиты](modules/m12-evasion/index.md) | Понимать AV/EDR/AMSI/ETW, собрать лоадер, обойти Defender в лабе |
| [M13 Initial access и C2](modules/m13-initial-access-c2/index.md) | Фишинг-инфраструктура, payload delivery, Sliver/Havoc, redirector |
| [M14 Pivoting и инфраструктура](modules/m14-pivoting-infra/index.md) | Туннели, SOCKS, Terraform/Ansible для C2-инфраструктуры |
| [M15 Операции и отчётность](modules/m15-rt-ops/index.md) | RoE, план эмуляции, отчёт уровня заказчика, debrief |

**Критерий выхода:** провести сквозную операцию «периметр → домен → DA» на своём стенде, уложиться в 8 часов, оставить таймлайн атаки, детекты и отчёт. Это ваш главный портфолио-кейс.

**Сертификации на этом этапе (по желанию):** OSCP (после этапа 1), CRTP/CRTO (после AD-модулей), PNPT как «дешёвый OSCP-аналог».

## Этап 4. Senior (работа + 2–4 года)

Здесь трек не заканчивается, а становится фоном. Что отличает senior:

| Компетенция | Как проверить |
|---|---|
| **Техническая глубина** | Объясняет механизм (не команду) и предсказывает поведение защиты |
| **Самостоятельность** | Ведёт операцию от скоупа до debrief без пинков |
| **Приоритизация** | Из 40 находок выбирает 3, которые реально меняют риск-профиль |
| **Коммуникация** | Отчёт читается CEO, а technical appendix — админом |
| **Безопасность операции** | Ни одного «сожжённого» домена/инфраструктуры за операцию |
| **Менторство** | Может научить junior и не сделать за него |
| **Исследование** | Публикует новое, а не только воспроизводит чужое |
| **Этика** | Отказывается от сомнительного скоупа и фиксирует это письменно |

**Сертификации для senior-трека:** OSEP, CRTO, CRTL, OSED (реверс), CISSP/CISM (если тянет в management), AWS Security Specialty / AZ-500 / CKS (если в cloud red team).

## Антипаттерны

- **Коллекционирование курсов.** 10 купленных курсов = 0 навыков. Один модуль до конца лучше.
- **Только видео.** Без рук через неделю не остаётся ничего.
- **Metasploit-туризм.** `msfconsole → exploit → shell` не учит ничему. Сначала вручную, потом автоматизация.
- **Игнорирование отчётности.** Senior отличается не тем, что ломает, а тем, что объясняет.
- **Атака всего подряд.** Один боевой IP в сканере — и трек закончился на статье 272.
- **Сравнение с инфлюенсерами.** Они показывают монтаж, а не 40 часов тупиков.
