# Capstone: сквозная операция «Northwind»

Финальная работа. Здесь нет пошаговых подсказок — только сценарий, правила и критерии. Это то, что вы покажете работодателю как «могу провести операцию целиком».

## Легенда

**Northwind Labs** — вымышленная компания. Периметр: один web-сервер. Внутри — домен `northwind.local`, файловый сервер с «коммерческой тайной», SIEM (если прошли M17).

Вы — red team по договору. Задача: доказать, что злоумышленник может добраться до финансовых документов, и показать, как это детектировать.

```
Интернет (имитация)
      │
   [LNX01]  10.10.10.30  web (DVWA/Juice Shop или свой сервис)
      │
   [DMZ] 10.10.10.0/24
      │
   [WS01] 10.10.10.20   Windows 11, пользователь helpdesk
      │
   [DC01] 10.10.10.10   northwind.local
      │
   [FS01] 10.10.10.60   файловый сервер, «Crown Jewel»
```

## Правила

- Только `10.10.10.0/24`, только свои ВМ.
- Разрешено: web-эксплуатация, privesc, AD-атаки, pivoting, C2 в локальной сети.
- Запрещено: DoS, шифрование, удаление логов, атаки на хост.
- Время: 16 часов чистой работы (можно 4 сессии по 4 часа).
- Артефакты обязательны: таймлайн, доказательства, отчёт.

## Фазы

1. **Recon** — карта сети, сервисы, версии, пользователи.
2. **Foothold** — доступ на LNX01.
3. **Pivot** — попадание в `10.10.10.0/24` и на WS01.
4. **AD** — от пользователя до Domain Admin.
5. **Objective** — доступ к `FS01` и файлу `finance_2026.xlsx` (создайте его сами).
6. **Detection** — какие события вы оставили, какие правила сработали/не сработали.
7. **Report** — executive summary + technical findings + remediation.

## Что сдать

```
labs/capstone/
├─ timeline.csv          # время, хост, действие, MITRE technique, результат
├─ findings.md           # 5–10 находок с критичностью и доказательствами
├─ report.md             # отчёт для заказчика (8–15 страниц)
├─ detections/           # Sigma/правила, которые ловят ваши шаги
├─ iocs.csv              # хэши, IP, домены, имена процессов
├─ debrief.md            # что сработало, что нет, чему научились
└─ evidence/             # скриншоты и выдержки (без реальных данных)
```

## Критерии оценки

| Критерий | Вес |
|---|---:|
| Достижение objective с доказательством | 25 |
| Полнота и корректность AD-пути | 20 |
| OPSEC: не сломали стенд, не вышли за scope | 15 |
| Качество детектов и разбор следа | 15 |
| Отчёт: структура, риск, remediation | 15 |
| Воспроизводимость (по отчёту можно повторить) | 10 |
