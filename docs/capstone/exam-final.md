# Capstone — экзамен

Три задачи. Можно сдавать по отдельности, но для «senior-track» нужны все три.

---

## 🟢 Задача 1. Foothold и первый отчёт (2–3 часа)

**Ситуация:** у вас есть только `LNX01` (10.10.10.30) с запущенным уязвимым web-приложением. Учётных данных нет.

**Задание:**
1. Проведите recon, определите приложение и версию.
2. Получите выполнение команд или доступ к файлам.
3. Найдите флаг `NW{...}` в `/var/www/`.
4. Оформите short-report на 2 страницы: что нашли, как, как чинить.

**Сдаётся:** `labs/capstone/green/` — команды, скриншот флага (обрезанный), short-report.md.

**Критерии:** доступ получен (40), объяснение уязвимости (25), remediation (20), OPSEC (15).

---

## 🟡 Задача 2. AD-путь до Domain Admin (4–6 часов)

**Ситуация:** у вас есть учётка `helpdesk` с паролем `Passw0rd!` и доступ в сеть `10.10.10.0/24`.

**Задание:**
1. Соберите BloodHound-карту и найдите кратчайший путь до DA.
2. Реализуйте путь минимум из двух шагов (например, ACL → Kerberoast → DA).
3. Получите `ntds.dit` или иной эквивалент полного контроля.
4. Для каждого шага укажите MITRE ATT&CK ID и событие, которое его ловит.

**Сдаётся:** `labs/capstone/yellow/` — граф/скриншот пути, команды, `path.md` с таблицей «шаг → техника → лог → детект».

**Критерии:** путь корректен (35), минимум два независимых шага (20), маппинг на MITRE и логи (25), отчёт (20).

---

## 🔴 Задача 3. Полная операция + purple-loop (8–16 часов)

**Ситуация:** полный стенд «Northwind». Есть SIEM с базовыми правилами (или поднимите Wazuh из M17).

**Задание:**
1. Пройдите всю цепочку: web → LNX01 → WS01 → DC01 → DA → FS01 → файл.
2. Ведите таймлайн с точностью до минуты.
3. После операции проанализируйте логи SIEM: какие шаги вы оставили, какие детекты сработали, какие — нет.
4. Напишите 3 новых Sigma-правила, которые закрывают слепые зоны, и проверьте их на повторной атаке (в снапшоте).
5. Сдайте отчёт заказчику: executive summary (1 страница), findings (5–10), remediation с приоритетами, technical appendix.

**Сдаётся:** `labs/capstone/red/` — timeline.csv, report.md, detections/, iocs.csv, debrief.md, evidence/.

**Критерии:**
- Objective достигнут и доказан: 25
- Цепочка и таймлайн: 20
- Детекты и проверка: 20
- Отчёт и приоритизация: 20
- OPSEC и воспроизводимость: 15

**Бонус (+10 к оценке, но не выше 100):** автоматизация одного из этапов (скрипт, Terraform, Ansible) с README и тестом.
