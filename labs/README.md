# Лаборатории: артефакты

Здесь лежат результаты практики: скрипты, конфиги, writeup, отчёты. Это вторая половина портфолио после сайта.

## Структура

```
labs/
├─ m00-start/
├─ m01-linux/
├─ m02-networking/
├─ m03-scripting/
├─ ...
├─ capstone/
└─ _template/
   ├─ writeup.md
   └─ README.md
```

## Правила именования

- Папка модуля: `mXX-короткое-имя` (совпадает с `docs/modules/`).
- Внутри: `lNN-тема/` — по номеру урока.
- Файлы: `writeup.md`, `solve.py`, `scan.sh`, `report.md`, `detections/`, `evidence/`.
- Крупные бинарники — не в git. Ссылка + SHA256 в writeup.

## Что считается артефактом

| Тип | Пример |
|---|---|
| Writeup | Разбор лабы с командами, выводом и «почему» |
| Скрипт | Автоматизация enum/скан/парсинг, с `--help` и README |
| Отчёт | Vuln report, red team report, detection report |
| Детект | Sigma/YARA/правило SIEM + тест |
| PoC | Минимальный воспроизводимый эксплойт для своей лабы |
| Схема | Диаграмма сети/атаки (draw.io, mermaid) |

## Чего не должно быть

- Реальных IP, доменов, имён, паролей.
- Готовых чужих эксплойтов без понимания.
- Дампов, pcaps и ключей (они в `.gitignore`).
- Инструкций, применимых к чужим системам без разрешения.

## Мини-шаблон

Скопируйте `_template/writeup.md` в папку урока и заполните. Пустой шаблон в репозитории — тоже нормально: он показывает структуру.
